# wowup

Usage:

```sh
# Update all my addons to the latest version
wowup update

# Install a new addon
wowup install BigWigs

# Remove an addon
wowup remove DeadlyBossMods
```

Configuration Stuff

* AddOns dir location
* List of addons
* Installed version of each addon (to check for update)
* List of folders installed by each addon (to support removal)


Download zips to a cache directory for easy reinstallation
